# Мир Valheim — CHUPIK

Сохранение кооп-мира **CHUPIK** (Valheim 1.0.x), автоматически выгруженное из папки Steam Cloud.
Репозиторий работает как бэкап: последний коммит = последнее сохранение мира.

## Состав мира

| Файл | Что это |
|---|---|
| `_main.<N>.fwl2` | заголовок мира: имя, пресет сложности, список игроков |
| `_main.<N>.db2` | данные мира: постройки, предметы, прогресс |
| `_main.<N>.chunks` | индекс чанков |
| `*.chunk` | участки мира (террейн, объекты) — их больше всего |
| `_main.<N>.ok` | маркер целостности сохранения |

`N` — номер сохранения, растёт с каждым сохранением в игре.

## Как обновить мир

Одна команда (игру лучше закрыть, чтобы файлы не были в процессе записи):

```bash
~/ValheimGit/update.sh
```

Скрипт сам делает `git add -A`, коммит с датой и `git push`. Копировать файлы из Steam-папки никуда не нужно:
рабочая папка git — это и есть папка мира в Steam Cloud, а метаданные git лежат отдельно в `~/ValheimGit/chupik.git`.

Если хочется вручную:

```bash
cd ~/.local/share/Steam/userdata/449915504/892970/remote/worlds/CHUPIK
git add -A && git commit -m "Мир CHUPIK: $(date '+%F %H:%M')" && git push
```

## Как восстановить мир

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/Luhzzi/valheim-chupik.git
   ```
2. Положить папку `CHUPIK` в каталог миров:
   - нативно: `~/.config/unity3d/IronGate/Valheim/worlds_local/`
   - через Proton: `~/.steam/steam/steamapps/compatdata/892970/pfx/drive_c/users/steamuser/AppData/LocalLow/IronGate/Valheim/worlds_local/`
3. Удалить лишнее (`README.md`, `.gitignore`), если игра будет ругаться на посторонние файлы — обычно не требуется.

## Замечания

- Внутри сейва есть ники игроков и два SteamID64 (открытые данные из профилей Steam) — секретов, паролей и ключей нет.
- Кэши миникарты (`cacheMinimap*`) в репозиторий не попадают: они пересоздаются игрой и весят несколько мегабайт.
